# Changelog

All notable changes to Forum Fighters. Versions follow `MAJOR.MINOR.PATCH` (see the README).

## 0.4.0
- New synthesized soundtrack: step sequencer with resonant bass, lead with vibrato, arpeggios and a full drum kit
- Separate themes for the title screen, character select and fights
- Fight music speeds up and gets busier in danger moments (a fighter below 25% health, or the final round)
- Fanfare sting when a round is won
- Game version shown in the bottom-right corner

## 0.3.0
- Four new fighters: Pat_00, master94ga, Mao-gp, Nkc90 (9 in total)
- Engine hooks for special mechanics: hype/haste, stance move sets, double jump, mid-air skills, whiff-punish bonus
- Manga / anime visual style: cel shading, rim lighting, tapered limbs, impact starbursts, sound-effect words, focus lines, screen tone, afterimages
- Title, select and How to Play screens adapt to the roster size

## 0.2.0
- Code split into modules (`js/core`, `js/render`, `js/game`, `js/characters`, `js/scenes`), one file per fighter
- `index.html` entry point; old `forum-fighters.html` link redirects
- README with controls, roster and project structure

## 0.1.0
- First playable version: 5 fighters (Talpaman, Gaara80, menoDZero, the.dark.player, Kyle_SR84)
- 1P vs CPU and 2P versus, best of 3 rounds, skills and supers, gamepad support
